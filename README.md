# IndoScript 🇮🇩

**IndoScript** adalah bahasa pemrograman berbasis interpreter yang ringan dan mudah digunakan. Proyek ini dilengkapi dengan antarmuka baris perintah (CLI) `indo` sehingga skrip IndoScript dapat dieksekusi secara global langsung dari terminal Anda.

---

## 🚀 Cara Instalasi

Anda dapat menginstal IndoScript langsung dari GitHub menggunakan `pip`:

```bash
pip install git+[https://github.com/raffisirojudin/indoscript.git](https://github.com/raffisirojudin/indoscript.git)
